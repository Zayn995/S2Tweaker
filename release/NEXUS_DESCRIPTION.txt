WHAT IT DOES
============
A small Windows tool with sliders and checkboxes. You pick your values,
it builds a .pak mod from them - no modding knowledge needed.

- ~130 tweaks in 7 tabs: health, stamina (incl. per-action costs),
  fall damage, walk/crouch & run/sprint speed, jump height, max carry
  weight + overweight penalty start, item weights per category,
  player/NPC/mutant damage & health, headshot multiplier, explosions,
  weapon & armor durability, jamming, spread, recoil, scoped aim sway,
  breath hold, anomaly damage, radiation, bleeding, hunger & sleepiness,
  trader prices & min. durability, repair & upgrade costs, quest rewards
- NEW in 1.5.0: MUTANT overhaul (speed & hearing sliders, per-species
  overrides for health/speed/damage incl. every attack, bloodsucker
  cloaking controls), ADS movement speed & magazine size & melee damage,
  anomaly damage PER TYPE (electro/chemical/fire/gravity), consumable
  strength, rain & emission frequency
- NEW in 1.4.0: ARMOR protection sliders per damage type (physical/
  burn/shock/chemical/radiation/PSY - your armor only, NPCs untouched),
  armor & exoskeleton carry-weight bonuses (0 % = none), and a rare
  artifact bias slider (shift rarity rolls toward Rare/Epic)
- NEW in 1.3.0: AMMO tweaks (damage, armor piercing, armor damage,
  cover penetration - each ammo type keeps its character), weapon
  EFFECTIVE RANGE and BLEEDING as full three-level weapon parameters,
  weapon and armor durability now SEPARATE sliders, detector & scanner
  range (Echo/Bear/Veles/Gilka + anomaly beeper), fast travel cost
  (0 % = free) and trader restock time
- NEW in 1.2.0 (your requests from the comments!): hit camera shake /
  aim punch 0-300 %, NPC reaction delay, experimental A-Life sliders
  (max simultaneous NPCs & mutants, spawn distance), artifact effect
  strength / radiation / spawn chance, save & load PRESETS, and a
  search box to find any of the ~120 sliders
- NEW in 1.1.0: weapon tweaks on THREE levels (global / 8 weapon
  categories / per-weapon overrides for 79 weapons incl. uniques -
  damage, spread, recoil, durability, fire rate), an "NPCs & AI" tab
  (accuracy, vision & hearing range, grenade usage, "NPCs don't
  self-heal"), per-category price factors, and a fix for the scoped-sway
  slider breaking the alternative offset aiming
- It reads the vanilla values from YOUR installed game version, so
  multiplier tweaks stay correct after game patches
- Only the values you CHANGE get patched - everything left on "(vanilla)"
  is untouched, so it won't conflict with your other mods


HOW TO USE (step by step)
=========================
 1. Download and extract the ZIP
 2. Create a folder, for example on your desktop:  Desktop\S2Tweaker
 3. Put S2Tweaker.exe (and README.txt) into that folder
 4. Run S2Tweaker.exe
 5. The tool suggests your game folder, e.g.
    C:\Games\Steam\steamapps\common\S.T.A.L.K.E.R. 2 Heart of Chornobyl
    Check it. If it's wrong, click "Browse ..." and select your game
    folder (the one that contains Stalker2\Content\Paks)
 6. Click "Confirm & load game data" and wait 10-20 seconds
    (only needed on first start and after game updates)
 7. Set your sliders and checkboxes. Everything you leave at "(vanilla)"
    will NOT be part of the mod
 8. Optional: change the mod name at the bottom
 9. Click "Build pak -> output folder"
10. Open  Desktop\S2Tweaker\output  - there is your mod, e.g.
    zzz_S2Tweaker_P.pak
11. Copy that file into:
    <your game folder>\Stalker2\Content\Paks\~mods\
    Example:
    C:\Games\Steam\steamapps\common\S.T.A.L.K.E.R. 2 Heart of Chornobyl\Stalker2\Content\Paks\~mods\
    If the ~mods folder doesn't exist, create it.
    (Shortcut: the "Install to ~mods" button does steps 9-11 in one
    click and creates the ~mods folder automatically)
12. Start the game. Done!


CHANGE OR REMOVE THE MOD
========================
- Change values: move the sliders, build again - the new pak replaces
  the old one (same mod name = same file name)
- Remove the mod: delete zzz_<YourModName>_P.pak from the ~mods folder,
  or click "Remove from ~mods" in the tool
- Uninstall the tool: just delete your S2Tweaker folder - settings,
  cache and output all live inside it (fully portable, nothing else is
  written anywhere)


GOOD TO KNOW
============
- After a game update: start the tool and confirm the game folder again -
  it detects the new version and re-reads the vanilla values automatically
- If you already use single-purpose mods that change the same values
  (e.g. "carry weight 200"), remove them - this tool covers them and its
  pak loads last anyway
- Some antivirus tools flag freshly built Python exes - this is a known
  false-positive pattern
- Debug checkbox: also exports the raw .cfg patch files to
  output\<ModName>_cfg so you can see exactly what the mod changes
