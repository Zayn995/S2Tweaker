--- File description (242 Zeichen) -------------------------------
The tool itself. Unzip everything into one folder, keep _internal next to the exe, run S2Tweaker.exe. One extra file is needed to read your game - the tool shows you where. No internet access of any kind. New: swap a weapon's ammunition type.

--- Changelog ----------------------------------------------------
1.20.0 - change which ammunition a weapon uses

- New: an "Ammunition" dropdown per weapon (Weapons tab, "Single weapon
  overrides", above the sliders). Requested on GitHub by Molkerr. Every
  caliber the game actually uses is offered.
- It does NOT change damage. Damage comes from the weapon - that is the
  Damage slider; the round only adds a multiplier, and that multiplier
  is the same for every rifle and pistol caliber. A swap changes
  penetration, bullet flight, price and how easy the ammo is to find.
- It changes NPC weapons too: the caliber lives on the weapon setup that
  player, NPC and boss versions share. The tool tells you how many item
  variants share the one you are about to change.
- Nothing is blocked, not even broken combinations. A rifle on shotgun
  shells drops to about 8 % of its damage; a shotgun on rifle rounds
  jumps to roughly 12x. The tool computes those numbers from your own
  game files, shows them, and then lets you do it.
- 7.62x39 is missing on purpose: no weapon uses it and it drops from no
  loot generator, so a weapon switched to it would never find ammo.
- No new game files, no re-extraction. Your existing paks stay valid.

1.19.2 - no network code, and no archive hidden inside the exe

- The executable was 90% compressed archive. Shipping as a folder in
  1.19.0 only moved the DLLs out; the Python code stayed inside
  S2Tweaker.exe as a 2,857,284-byte compressed blob with an entropy of
  7.999 out of 8.0. A small loader in front of a large opaque block is
  what a packer looks like, and it is how analysts recognise malware
  built with the same tooling. The code now ships as ordinary files
  beside the exe: the program file is 345 KB instead of 3.2 MB, and one
  of the three scanners that flagged it stopped.
- The update check is gone, and with it every trace of networking - no
  urllib, no sockets, no HTTP client. Nexus' own file guidelines
  prohibit executables that connect to the internet "unless where it is
  crucial" and state that "'auto update' functionality does not qualify
  as crucial". They are right, so it is out. You can verify that with
  one search of the public source.
- To update from now on: download the new ZIP and replace S2Tweaker.exe
  and the _internal folder next to it. Settings, presets, cache and
  built mods are never touched. The version is in the window title.
- This download is the build server's own output, taken from the public
  GitHub Actions run and uploaded unchanged. Nothing in it was built on
  a private machine.
- No new game files, no re-extraction. Your existing paks stay valid.

1.19.1 - nothing is downloaded while the tool runs

- The tool no longer fetches anything at runtime. It used to download the
  Oodle decompression library on first use and load it, which is exactly
  what a dropper does and one reason scanners flagged it. That code is
  gone. A setup window now walks you through placing that file once, with
  pictures, and shows where it goes. It only appears when the file is
  missing, and an indicator in the header shows the state at a glance.
- The pak tool it bundles (repak) is built from source with its download
  function and whole HTTP/TLS stack removed, so it cannot fetch anything
  either. It is no longer a third-party prebuilt binary.
- Sorry about the one manual step. The library may not be shipped, cannot
  be taken out of the game (it is compiled into the game executable), and
  the open re-implementations have no licence. Doing it automatically was
  the old answer, and that is what got this tool flagged.

1.19.0 - shipped as a folder instead of a single exe

- The exe was a self-extracting archive that unpacked into your temp
  folder and ran from there - harmless, but the shape of a dropper. Now a
  launcher next to an "_internal" folder. Keep them together.
- The exe finally identifies itself: publisher, product, version, licence.
- Fixed three weapons offering a "Durability" slider that could never do
  anything (they have no durability value in the game data).
- New test suite checking every slider against your game's real values:
  over 3,000 checks, no wrong values found.
